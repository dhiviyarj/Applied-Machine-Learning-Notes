# Web References

The following external resource supports the concepts and classroom activities covered in this machine learning course.

## Google Machine Learning Crash Course

[Open the Google Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course)

Google's Machine Learning Crash Course provides interactive lessons, explanations, visualizations, exercises, and programming activities on fundamental machine learning concepts.

### Recommended use

- Review a topic after studying the corresponding unit lecture slides.
- Use the interactive exercises to reinforce concepts discussed in class.
- Compare Google's examples with the problems in the course activity sheets.
- Revisit prerequisite topics when additional explanation is required.

### Relevant topics

- Introduction to machine learning
- Linear and logistic regression
- Loss functions
- Gradient descent and model optimization
- Classification and evaluation metrics
- Generalization, overfitting, and regularization
- Neural networks and embeddings

> This is an external learning resource maintained by Google. Its content and availability may change over time.
